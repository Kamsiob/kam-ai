# Does this message ask Brainstorm for an output, or is it a disclosure?
#
# Built before implementing anything, so the gate is measured rather than judged
# by whoever wrote it (#129).
#
# The distinction is deliberately NOT emotional temperature. Frustration and
# distress read almost identically, and Brainstorm's entire audience arrives
# stuck and frustrated, so a gate keyed to how upset someone sounds refuses the
# people the mode exists for. That was tried and reverted. The question is
# whether they are asking for something to be produced.
#
# Format: VERDICT<TAB>message
#   WORK      a workable request; Brainstorm must engage
#   DISCLOSE  a personal disclosure with no request; Brainstorm should decline
#
# Written the way people actually type, including the ones who are angry, the
# ones who are despairing about work, and the ones who mention something
# upsetting while genuinely asking for help with a task. Those three groups are
# where a naive gate fails.
